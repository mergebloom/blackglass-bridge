# Security policy

Do not publish credentials, vault content, proprietary application artifacts,
or a working exploit in a public issue. Use the hosting provider's private
security-advisory channel when this repository is published.

Reports should include the affected Blackglass version, upstream renderer version
and SHA-256, expected safety invariant, reproduction using disposable data, and
impact. Remove tokens, passwords, absolute user paths, and note contents.

The supported security boundary is described in `docs/architecture.md`.
Unqualified renderer releases and redistributed proprietary app bundles are
outside the supported scope.
